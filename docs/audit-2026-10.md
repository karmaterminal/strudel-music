# strudel-music audit, 2026-10

Done for #65 ("Resurrect strudel-music"). `main` was audited at `1bab7d6` (2026-04-17) on
2026-10-03, from a clean clone in a cloud container. Every number below comes from a command in
the proof log at the end.

## Summary

- **A clean checkout works.** Setup, the smoke test and a render succeed, and the render passes
  the QA gate: `fog-and-starlight`, 16 cycles, 64 s of audio in under a second, −14.4 LUFS, true
  peak −3.0 dBFS, no dropouts.
- **Fixed in #73:**
  - Both renderers played a number in `note()` as Hz instead of a MIDI note.
  - `dispatch.sh play` ignored its channel argument.
  - The ignore rules kept `samples/strudel.json` out of the ClawHub bundle.
  - `SKILL.md` metadata that OpenClaw and ClawHub reject or drop.
  - An onboarding example that didn't render as written.
- **Still broken, with issues filed:**
  - 10 of 15 shipped compositions name sounds setup never installs (#66).
  - Two renderers that disagree (#67).
  - No reverb, delay, highpass or distortion (#68).
  - An auto-publish job whose last two runs failed (#69).
  - Repo hygiene (#72).
  - Work stranded on branches (#61, reopened).
- **Not verified here:** ClawHub install, update and uninstall (#70). This container's network
  policy blocks clawhub.ai. Voice streaming wasn't run either: it needs a bot token and a voice
  channel. Its argument passing has a test now.

## Distribution

### OpenClaw

OpenClaw 2026.9.8's own `parseSkillFrontmatter` and `resolveSkillManifestMetadata`, run on each
version of `SKILL.md`:

| | `main` (1bab7d6) | #73 |
|---|---|---|
| Frontmatter keys | name, description, version, author, license, tags, metadata | name, description, metadata |
| `requires` | bins: node; anyBins: ffmpeg | bins: node |
| Installers kept | uv demucs only (`script` setup and `apt` ffmpeg dropped) | brew ffmpeg, uv demucs |
| User-invocable | yes | yes |

- **Command name.** OpenClaw sanitizes the skill name to `strudel_music` (`sanitizeSkillCommandName`).
- **Install.** Per OpenClaw's docs (`docs/cli/skills.md`):
  - `openclaw skills install git:karmaterminal/strudel-music` installs from Git. It needs
    `SKILL.md` at the repo root, as here.
  - `openclaw skills install @<owner>/strudel-music` installs from ClawHub.
  - `openclaw skills check` lists missing requirements.
  - Removal uses the ClawHub CLI: `clawhub --workdir <workspace> uninstall @<owner>/strudel-music`.
- **Setup after install.** Installing copies files only, so `npm run setup` must run in the
  installed folder. SKILL.md says so.
- **Exec.** A long `exec` moves to the background after `yieldMs` (10 s by default). `background`
  and `timeoutSeconds` are the current parameters, and `sessions_spawn` takes `mode` and
  `runTimeoutSeconds`.
- **Not run here:** an actual OpenClaw install (#70).

### ClawHub

- **What's live is unknown.** clawhub.ai is blocked from this container. The last two CI
  publishes failed (1.2.1, run 22561112407; 1.2.2, run 22595366975).
- **Metadata.** The old metadata fails ClawHub 0.23.3's `ClawdisSkillMetadataSchema`
  (`install[0].kind must be "brew", "go", "node" or "uv" (was "script")`, and the same for
  `apt`). The new metadata passes, `envVars` included.
- **Bundle,** computed with the CLI's own file selection (`.gitignore`, `.clawhubignore`, no dot
  paths):

  | | Files | Bytes | `samples/strudel.json` | Contributor files |
  |---|---|---|---|---|
  | `main` 1bab7d6 | 86 | 2,313,943 | missing | n/a |
  | #73 | 87 | 2,306,586 | included | left out (`test/`, `AGENTS.md`, `CLAUDE.md`, this file) |

  The bundle includes `assets/banner.png` (1.7 MB) and all of `src/compositions/`. It leaves out
  the 32 committed `bloom_*` WAVs (`*.wav`), so the bloom studies can't find their samples in a
  ClawHub install.
- **Plugin folders.** ClawHub refuses to publish a skill folder that looks like a plugin:
  `.claude-plugin/plugin.json`, `openclaw.plugin.json`, `.codex-plugin`, `.cursor-plugin`, or a
  `package.json` with an `openclaw` key. A Claude Code plugin has to live under `plugins/` (#71).
- **License.** ClawHub publishes every skill as MIT-0; this repo is MIT. SKILL.md no longer
  carries `license: MIT`. Confirm MIT-0 before the next publish (#69).
- **Publishing** stays a separate decision, made by figs (#69). This pull request publishes
  nothing.
